Présentation de l’épreuve E5

Structure conseillée : contexte -> objectifs -> réalisations -> compétences -> outils -> bilan. Les sections ci-dessous sont volontairement "modulaires" pour être modifiées rapidement.

1) Présentation de l’épreuve

L'epreuve E5 evalue la capacite a realiser des activites professionnelles en lien avec le BTS SIO, a presenter des productions, et a argumenter les choix techniques. L'objectif est de demontrer une demarche structuree, des competences validees et une communication claire.

2) Contexte

  • Organisation : [ecole / entreprise / projet personnel]
  • Besoin : [probleme a resoudre / objectif]
  • Perimetre : [ce qui est inclus / exclu]
  • Contraintes : [temps, securite, materiel, normes...]

3) Compétences développées

  • Analyse du besoin et redaction d'une solution
  • Conception (maquettes / architecture / schema)
  • Developpement / deploiement / tests
  • Documentation (procedure, guide utilisateur)
  • Communication (compte-rendus, presentation)
